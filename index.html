Java Backend Разработчик

Июль 2024 – Ноябрь 2024

Стек: Java, Spring, PostgreSQL + Flyway, MongoDB, Kafka, Redis, JUnit, Mockito

Разработал backend систему, способную выдерживать большие нагрузки, для большого сервиса, предоставляющего услуги учителям и репетиторам по помощи в их деятельности

Моя сфера деятельности:

  • Спроектировал базу данных: разрабатал структуру базы данных, включая схемы для хранения информации о пользователях, заданиях, результатах решений и рекомендациях. Использовал PostgreSQL для основных данных и MongoDB для хранения данных, которые требовали большей гибкости
  • Разработка API: cпроектировал и реализовал REST API для различных функций сервиса, например таких как создание и отправка домашних заданий, получение решений учеников, оценка результатов и генерация новых заданий на основе рекомендаций ИИ
  • Разработка микросервисной архитектуры: разделил один большой сервис на микросервисы, реализовал общение между ними с помощью REST и Kafka
  • Настройка DevOps процессов: использовал Docker и Docker-compose для контейнеризации сервисов, настраивал автоматизированные миграции базы данных с помощью Flyway
